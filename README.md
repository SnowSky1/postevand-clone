# postevand-clone

仿照 [Postevand](https://postevand.com/)（丹麦饮用水品牌 Shopify 商城）开发的前端静态项目，仅用于前端学习与技术研究。

## 本地预览

```bash
python -m http.server 8091
```

浏览器打开 <http://127.0.0.1:8091/>

## 内容

- 店铺页面：首页、产品、集合（collections）、购物车、结账、搜索、博客
- Shopify 主题资源，cdn.shopify.com 等第三方静态资源已本地化，可完全离线渲染
